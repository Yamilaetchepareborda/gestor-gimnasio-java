# 🏋️‍♀️ Gestor de Gimnasio
### Java · Swing · DAO · MySQL · MVC

Aplicación de escritorio desarrollada en **Java** para la gestión integral de un gimnasio, con interfaz gráfica y persistencia en base de datos.

---


## 📌 Descripción
Este proyecto permite administrar clientes, actividades y entrenadores de un gimnasio a través de una interfaz gráfica construida con **Java Swing**.  
Está organizado bajo una arquitectura **MVC**, utilizando el patrón **DAO** para el acceso a datos y **MySQL** como sistema de persistencia.

Fue desarrollado como trabajo académico, poniendo especial foco en la **organización del código**, la **separación de responsabilidades** y el uso de buenas prácticas.

---

## ⚙️ Funcionalidades
✔ Alta, baja y modificación de clientes  
✔ Gestión de actividades del gimnasio  
✔ Asociación de clientes a actividades  
✔ Persistencia de datos en MySQL  
✔ Interfaz gráfica con Java Swing  
✔ Validaciones básicas de datos  

---

## 🏗️ Arquitectura
El proyecto sigue el patrón **MVC (Model–View–Controller)**:

- **Model** → entidades del dominio (Cliente, Actividad, Entrenador, etc.)  
- **DAO** → acceso a datos y consultas SQL  
- **Controller** → lógica de negocio  
- **View** → interfaces gráficas desarrolladas con Swing  
- **Util** → conexión y utilidades de base de datos  

Esta estructura permite un código más mantenible y escalable.

## 🗄️ Base de datos
El sistema utiliza **MySQL** para la persistencia de la información.

> 🔐 **Seguridad:**  
> Las credenciales de conexión no se incluyen en el repositorio.  
> El archivo `ConexionBD.java` debe configurarse con los datos locales del usuario.
